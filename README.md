# Lorre Li — Portfolio

Minimal serif portfolio site built with Next.js.

## Getting Started

```bash
npm install
npm run dev
```

## Customize Content

All rendered content lives in `app/content.js` — profile, intro, beliefs,
timeline, and projects. Inline links inside text use `[label](url)`.
